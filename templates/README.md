# 模板（可选）

`templates/` **默认是空的**——没有模板文件时，报告由 `src/wreport/weekly.py` 里的内置格式生成，
那是唯一的事实来源，不存在第二份格式定义。

只有当你放了 `templates/weekly.md` **并且**文件里含 `{{...}}` 占位符时，它才会被用作外层骨架。

## 可用占位符

| 占位符 | 内容 |
|---|---|
| `{{title}}` | `📋 本周工作周报 · 2026 W39（09/21 – 09/27）` |
| `{{week}}` | `2026-W39` |
| `{{meta}}` | 生成信息（当前为空串） |
| `{{body}}` | 正文（从第一个 `## ` 开始，含全部章节） |

## 示例

```markdown
<!-- templates/weekly.md -->
# 周报 / {{week}}

> {{meta}}

{{body}}

---

_由 `wreport weekly build` 生成，请勿手工编辑；改动会被下次生成覆盖。_
```

放了模板之后，`wreport weekly build --week 2026-W39` 会用上面的骨架包住正文。
删掉这个文件即恢复内置格式。
